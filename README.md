## Sections Overview

### 1. [Unit I - Fundamentals of OOP](OOP-Cpp-Unit-I/)
- Basic data types, conditionals, loops, functions, classes and objects, constructors, destructors, static members.
- Lab Programs: Smart Agriculture Sensor Monitor, Student Attendance System, E-Commerce Product Catalog.

### 2. [Unit II - Inheritance](OOP-Cpp-Unit-II/)
- Single, multilevel, hierarchical, multiple inheritance, virtual base classes, friend and nested classes.
- Lab Programs: Employee Payroll System, Digital Payment Gateway, Vehicle Fleet Management.

### 3. [Unit III - Polymorphism](OOP-Cpp-Unit-III/)
- Compile-time polymorphism (function overloading, operator overloading) and runtime polymorphism (virtual functions, abstract classes).
- Lab Programs: CAD Shape Drawing System, Complex Number Calculator, Input Validation Service.

### 4. [Unit IV - Files and Streams](OOP-Cpp-Unit-IV/)
- File I/O (`ifstream`, `ofstream`, `fstream`), text and binary files, file pointers (`seekg`, `seekp`, `tellg`, `tellp`).
- Lab Programs: Student Record File System, Server Log Analyzer, Binary File for Fixed-Size Records.

### 5. [Daily Coding Practice](OOPS-DAILY-COADING/)
- Day-to-day hands-on practice programs in C++.
