## Sections Overview

### 1. [Unit I - Fundamentals of OOP](OOP-Cpp-Unit-I/)
- Basic data types, conditionals, loops, functions.
- Class and object creation, constructors, destructors, static members, friend functions.
- Lab Programs: Smart Agriculture Sensor Monitor, Student Attendance System, E-Commerce Product Catalog.

### 2. [Unit II - Inheritance & Polymorphism](OOP-Cpp-Unit-II/)
- Single, multilevel, hierarchical, multiple inheritance, and virtual base classes.
- Friend classes, nested classes, function overriding, and abstract classes.
- Lab Programs: Employee Payroll System, Digital Payment Gateway, Vehicle Fleet Management.

### 3. [Daily Coding Practice](OOPS-DAILY-COADING/)
- Day-to-day hands-on practice programs in C++.

```bash

g++ program01.cpp -o program01
./program01

cd OOP-Cpp-Unit-II/Program_01
```
