## List of Programs

### 1. Program 01: Smart Agriculture Sensor Monitor
- **File**: `Program_01/program01.cpp`
- **Description**: This program models a soil moisture sensor using a class `SoilSensor`. It stores sensor ID, moisture level, and time, and updates sensor readings dynamically using member functions.

### 2. Program 02: Student Attendance Management System
- **File**: `Program_02/program02.cpp`
- **Description**: This program manages student attendance records using a class `Student`. It tracks total classes and present days, and calculates attendance percentage.

### 3. Program 03: E-Commerce Product Catalog
- **File**: `Program_03/program03.cpp`
- **Description**: This program creates an online product catalog using a class `Product`. It demonstrates static data members and static member functions to keep track of total active products.
